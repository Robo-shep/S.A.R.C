# S.A.R.C — Super Acrobatic Rocket Cars

Rocket League-inspired 2D game with a PPO-trained AI agent. Built with pygame + numpy for physics, PyTorch for RL.

---

## File Map

| File | Purpose |
|---|---|
| `engine.py` | 2-player human game using `pygame.math.Vector2`. Standalone playable. |
| `enginenumpy.py` | Same game, physics refactored to numpy arrays. Standalone playable. |
| `Ordert/main_train.py` | **Primary training script.** Headless PPO training with curriculum + self-play. |
| `Ordert/train_ppo.py` | Older hybrid: live pygame rendering while AI trains vs human. |
| `Ordert/visualize.py` | Loads a saved model, plays AI vs human, spawns a second window showing NN internals. |
| `curriculum_brain.pth` | Active model checkpoint — the "brain" used by training and visualizer. |
| `saved_agents/` | Snapshots every 100k steps, used as Hall of Fame opponents. |
| `assets/` | `blue_car.png`, `red_car.png` sprites for pygame renders. |
| `penv/` | Project virtualenv — activate with `source penv/bin/activate`. |

---

## How to Run

```bash
source penv/bin/activate

# Play 2-player (WASD + arrow keys)
python engine.py

# Train headless (saves to curriculum_brain.pth)
python Ordert/main_train.py

# Visualize saved brain vs human
python Ordert/visualize.py
# -> Select 2 for curriculum model
```

## Physics Architecture

Physics is **duplicated** across all files — there is no shared physics module yet. Any constant change must be applied everywhere.

### Arena
- Screen: 1200×1000px
- Arena: 1000×800px (100px offset on all sides)
- Chamfered corners: 80px cut at 45°
- Goals: 200px tall, 80px deep, on left/right walls

### Objects
- `Ball`: mass=1, radius=22
- `Car`: mass=10, radius=20 (circle for broad phase), hitbox=40×24 (OBB for car-ball collision)
- Car hitbox and visual sprite dimensions are intentionally different — don't unify them

### Constants (identical in all files)
```python
DRAG = 0.99
TIRE_GRIP_NORMAL = 0.95 / TIRE_GRIP_DRIFT = 0.05
ACCEL = 0.08 / BOOST_ACCEL = 0.15
MAX_SPEED = 6.0 / BOOST_MAX_SPEED = 9.0
MAX_BOOST = 100.0  # boost drains at 0.15/step, regen at 0.03/step
BALL_ELASTICITY = 0.8 / CAR_WALL_ELASTICITY = 0.5
BALL_DRAG = 0.999
PHYSICS_SUBSTEPS = 8  # per frame — do not lower, causes instability
```

### Collision pipeline (per substep)
1. `resolve_arena_collisions` — goal posts first (circular), then flat walls, then net interior, then chamfered corners
2. `resolve_car_ball` — OBB vs circle in car-local space, impulse response
3. `resolve_car_car` — circle-circle, symmetric push

## PPO Agent

### Observation space (15 dims, normalized)
```
[my_x/W, my_y/H, my_vx/10, my_vy/10, cos(angle), sin(angle), boost/100,
 ball_x/W, ball_y/H, ball_vx/10, ball_vy/10,
 opp_x/W, opp_y/H, opp_vx/10, opp_vy/10]
```

### Symmetry trick
Car2's observation is generated by **mirroring the entire arena** (flipping positions and negating velocities) so both agents share the same action space. The "from my perspective, I'm always on the left attacking right" invariant must be preserved.

### Action space (4 dims, continuous, clipped to [-1, 1])
`[throttle, turn, boost (>0 = on), drift (>0 = on)]`

### Network
`ActorCritic`: two separate 128→128→output Tanh MLPs (actor + critic). State dim=15, action dim=4.

### Hyperparameters
```python
LR = 0.0003
GAMMA = 0.99
K_EPOCHS = 10
EPS_CLIP = 0.2
ACTION_STD_INIT = 0.6
UPDATE_TIMESTEP = 5000
```

## Curriculum Learning (main_train.py)

Three stages, controlled by `START_STAGE`:

| Stage | Name | Setup | Promotion |
|---|---|---|---|
| 0 | Ball Chasing | Car spawns facing ball, no opponent | 1000 ball touches |
| 1 | Striker | Random positions, no opponent | 1000 goals scored |
| 2 | League Play | Standard kickoff, full opponent | Runs indefinitely |

### Opponent selection in Stage 2
- 20% dumb (stationary drift)
- 20% historical (random snapshot from `saved_agents/`)
- 60% self-play (current policy weights)

### Saving
- `curriculum_brain.pth` — updated every 5000 steps
- `saved_agents/agent_{step}.pth` — snapshot every 100k steps

## Reward Function (main_train.py)

| Signal | Value |
|---|---|
| Score goal | +30 |
| Concede goal | -30 |
| Ball touch | +1.0 + directional shoot bonus (×1.0 of vel toward goal) |
| Save (touch ball near own net) | +5.0 |
| Enemy touches ball | -0.5 |
| Ball moving toward own goal | -0.05 × vel |
| Time step | -0.001 |
| Proximity to ball (<500px) | +(500-d)×0.0001 |
| Boost conservation (>30) | +0.005/step |
| Wall hugging (>30 steps) | -0.05/step |
| Episode timeout | 1500 steps |

## Key Invariants — Don't Break These

1. **Physics substeps = 8.** Lowering it causes collision tunneling at high speeds.
2. **Car hitbox = 40×24, sprite = 55×28.** They're intentionally different — hitbox is tighter than visual.
3. **Arena constants must match** between the training env and any visualizer/game engine, or the AI will behave incorrectly when played interactively.
4. **Observation normalization denominators** (`SCREEN_W`, `SCREEN_H`, `10`) must not change without retraining from scratch.
5. **The symmetry flip in `_get_obs_pair`** is load-bearing — both cars must receive equivalent observations or training diverges.
